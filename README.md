## 🔐 API Security Tools

- **[OWASP ZAP](https://www.zaproxy.org/)** — Web application security scanner
- **[Burp Suite](https://portswigger.net/burp)** — Web vulnerability scanner & proxy

- **[Insomnia](https://insomnia.rest/)** — Open-source API client
